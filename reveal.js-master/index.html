3️⃣ Listas Enlazadas

👤 Pablo Rojas

Características

  • Estructuras dinámicas formadas por nodos
  • Cada nodo contiene: dato + referencia al siguiente
  • No requieren memoria contigua
  • Eficientes para inserciones/eliminaciones frecuentes

Tipos

  • Simple: Cada nodo → siguiente (A → B → C → None)
  • Doble: Cada nodo ⇄ anterior y siguiente

Código: Lista Simple (Parte 1)

💻 Nodo y Estructura
# Clase Nodo
class Nodo:
    def __init__(self, materia):
        self.materia = materia
        self.siguiente = None

# Clase Lista Enlazada Simple
class ListaEnlazadaSimple:
    def __init__(self):
        self.cabeza = None

    def agregar(self, materia):
        nuevo = Nodo(materia)
        if not self.cabeza:
            self.cabeza = nuevo
        else:
            actual = self.cabeza
            while actual.siguiente:
                actual = actual.siguiente
            actual.siguiente = nuevo

    def mostrar(self):
        actual = self.cabeza
        while actual:
            print(actual.materia, end=" -> ")
            actual = actual.siguiente
        print("None")

Código: Lista Simple (Parte 2)

💻 Operaciones Adicionales
    def mostrar_posicion(self, pos):
        actual = self.cabeza
        i = 0
        while actual:
            if i == pos:
                print(actual.materia)
                return
            actual = actual.siguiente
            i += 1
        print("Posición fuera de rango")

    def modificar(self, pos, nueva_materia):
        actual = self.cabeza
        i = 0
        while actual:
            if i == pos:
                actual.materia = nueva_materia
                return
            actual = actual.siguiente
            i += 1

    def eliminar(self, materia):
        actual = self.cabeza
        anterior = None
        while actual:
            if actual.materia == materia:
                if anterior:
                    anterior.siguiente = actual.siguiente
                else:
                    self.cabeza = actual.siguiente
                return
            anterior = actual
            actual = actual.siguiente

Código: Implementación de Pila (Parte 1)

💻 Clase Nodo y Pila
# Definimos un nodo que guarda el dato y una referencia al siguiente
class Nodo:
    def __init__(self, dato):
        self.dato = dato
        self.siguiente = None

# Definimos la clase Pila
class Pila:
    def __init__(self):
        self.tope = None  # El elemento superior de la pila

    def esta_vacia(self):
        return self.tope is None

    def push(self, dato):
        """Agrega un nuevo elemento a la pila"""
        nuevo_nodo = Nodo(dato)
        nuevo_nodo.siguiente = self.tope  # El nuevo nodo apunta al anterior tope
        self.tope = nuevo_nodo  # Ahora el nuevo nodo es el tope

    def pop(self):
        """Elimina y devuelve el elemento superior de la pila"""
        if self.esta_vacia():
            print("La pila está vacía.")
            return None
        dato = self.tope.dato
        self.tope = self.tope.siguiente  # El nuevo tope es el siguiente nodo
        return dato

Código: Implementación de Pila (Parte 2)

💻 Métodos Adicionales
    def ver_tope(self):
        """Devuelve el elemento superior sin eliminarlo"""
        if self.esta_vacia():
            print("La pila está vacía.")
            return None
        return self.tope.dato

    def mostrar(self):
        """Muestra todos los elementos de la pila"""
        actual = self.tope
        print("Pila (de arriba hacia abajo):")
        while actual:
            print(f"→ {actual.dato}")
            actual = actual.siguiente

# Ejemplo de uso
pila = Pila()
pila.push("A")
pila.push("B")
pila.push("C")
pila.mostrar()

print("\nElemento en el tope:", pila.ver_tope())
print("Elemento sacado:", pila.pop())
pila.mostrar()

Código: Implementación de Cola

💻 Clase Cola
# Clase Cola
class Cola:
    def __init__(self):
        self.items = []  # Usamos una lista interna para guardar los elementos

    def esta_vacia(self):
        """Devuelve True si la cola está vacía."""
        return len(self.items) == 0

    def encolar(self, elemento):
        """Agrega un elemento al final de la cola (enqueue)."""
        self.items.append(elemento)

    def desencolar(self):
        """Saca el primer elemento de la cola (dequeue)."""
        if self.esta_vacia():
            print("La cola está vacía, no se puede desencolar.")
            return None
        return self.items.pop(0)  # pop(0) quita el primer elemento

    def ver_primero(self):
        """Devuelve el primer elemento sin quitarlo."""
        if self.esta_vacia():
            return None
        return self.items[0]

    def tamaño(self):
        """Devuelve el número de elementos en la cola."""
        return len(self.items)

    def __str__(self):
        """Representación en texto de la cola."""
        return f"Cola: {self.items}"

Código: Uso de Cola

💻 Ejemplo de Uso
# Ejemplo de uso:
cola = Cola()

cola.encolar("Cliente 1")
cola.encolar("Cliente 2")
cola.encolar("Cliente 3")

print(cola)  # Muestra el contenido de la cola

print("Atendiendo:", cola.desencolar())
print("Siguiente en la cola:", cola.ver_primero())
print("Tamaño actual:", cola.tamaño())

print(cola)

6️⃣ Conjuntos y Diccionarios

👤 Luis Quiroz

Conjuntos (set)

  • Sin elementos duplicados
  • No mantienen orden
  • Operaciones matemáticas: ∪, ∩, -
  • Búsqueda rápida O(1)

Diccionarios (dict)

  • Pares clave-valor
  • Claves únicas
  • Acceso O(1) por clave
  • Implementados con hash tables

Casos de uso

Sets: Eliminar duplicados, membresía rápida, operaciones de conjuntos

Dicts: Cachés, contadores, índices, configuraciones, mapeo de datos

Código: Conjuntos

💻 Operaciones con Sets
# Definir conjuntos
frutas_hoy = {"manzana", "plátano", "naranja", "mango"}
frutas_almacen = {"manzana", "pera", "sandía", "mango"}

# Operaciones de conjuntos
nuevas_frutas = frutas_hoy - frutas_almacen  # Diferencia
print("Frutas nuevas:", nuevas_frutas)  # {'plátano', 'naranja'}

repetidas = frutas_hoy & frutas_almacen  # Intersección
print("Frutas repetidas:", repetidas)  # {'manzana', 'mango'}

todas = frutas_hoy | frutas_almacen  # Unión
print("Todas las frutas:", todas)

# Eliminar duplicados de una lista
numeros = [1, 2, 2, 3, 3, 3, 4, 5, 5]
sin_duplicados = list(set(numeros))  # [1, 2, 3, 4, 5]

7️⃣ Árboles (Trees)

👤 Jesús Alvarado

Estructura Jerárquica

Estructura de datos no lineal formada por nodos conectados mediante relaciones padre-hijo.

Conceptos clave

  • Raíz: Nodo principal del árbol
  • Padre/Hijo: Relaciones entre nodos conectados
  • Hoja: Nodo sin hijos
  • Altura: Número de niveles del árbol
  • Subárbol: Árbol formado por un nodo y sus descendientes

Árbol Binario de Búsqueda (BST)

Propiedad BST

Para cada nodo:

  • Valores del subárbol izquierdo son menores
  • Valores del subárbol derecho son mayores

Recorridos DFS: In-order (1,4,5,6,7,8,9) • Pre-order (6,4,1,5,8,7,9) • Post-order (1,5,4,7,9,8,6)

Código: BST (Parte 1 - Estructura)

💻 Clases Node y BST
# Clase Nodo
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

# Clase Árbol Binario de Búsqueda
class BinarySearchTree:
    def __init__(self):
        self.root = None

    def insert(self, value):
        """Inserta un valor manteniendo la propiedad BST"""
        if self.root is None:
            self.root = Node(value)
        else:
            self._insert_recursive(self.root, value)

    def _insert_recursive(self, current_node, value):
        if value < current_node.value:
            if current_node.left is None:
                current_node.left = Node(value)
            else:
                self._insert_recursive(current_node.left, value)
        elif value > current_node.value:
            if current_node.right is None:
                current_node.right = Node(value)
            else:
                self._insert_recursive(current_node.right, value)

Código: BST (Parte 2 - Recorridos)

💻 Métodos de Recorrido DFS
    def in_order(self):
        """Recorrido In-order: Izq -> Raíz -> Der"""
        print("In-order:", end=" ")
        self._in_order_recursive(self.root)
        print()

    def _in_order_recursive(self, node):
        if node:
            self._in_order_recursive(node.left)
            print(node.value, end=" ")
            self._in_order_recursive(node.right)

    def pre_order(self):
        """Recorrido Pre-order: Raíz -> Izq -> Der"""
        print("Pre-order:", end=" ")
        self._pre_order_recursive(self.root)
        print()

    def _pre_order_recursive(self, node):
        if node:
            print(node.value, end=" ")
            self._pre_order_recursive(node.left)
            self._pre_order_recursive(node.right)

    def post_order(self):
        """Recorrido Post-order: Izq -> Der -> Raíz"""
        print("Post-order:", end=" ")
        self._post_order_recursive(self.root)
        print()

    def _post_order_recursive(self, node):
        if node:
            self._post_order_recursive(node.left)
            self._post_order_recursive(node.right)
            print(node.value, end=" ")

Código: BST (Parte 3 - Uso)

💻 Ejemplo Completo
# Crear el árbol BST
bst = BinarySearchTree()

# Insertar valores
values_to_insert = [6, 4, 8, 1, 5, 9, 7]
print(f"Insertando valores: {values_to_insert}")

for value in values_to_insert:
    bst.insert(value)

print("\n--- Resultados de Recorridos ---")

# In-order: Da los elementos ordenados
bst.in_order()
# Salida: In-order: 1 4 5 6 7 8 9

# Pre-order: Útil para copiar el árbol
bst.pre_order()
# Salida: Pre-order: 6 4 1 5 8 7 9

# Post-order: Útil para eliminar el árbol
bst.post_order()
# Salida: Post-order: 1 5 4 7 9 8 6

Aplicaciones de Árboles

BST

  • Búsqueda eficiente
  • Ordenamiento
  • Índices de bases de datos
  • Autocompletado

Otros tipos

  • Heap: Colas de prioridad
  • Trie: Búsqueda de texto
  • B-Tree: Sistemas de archivos
  • Red-Black: Balanceo automático

Ventajas: Búsqueda O(log n) en promedio, inserción/eliminación eficientes

Desventajas: Pueden desbalancearse (peor caso O(n)), requieren más memoria que arrays

✅ Conclusiones

Resumen de Estructuras

  • Arrays/Listas: Acceso rápido por índice, búsqueda secuencial
  • Listas Enlazadas: Inserciones/eliminaciones eficientes, sin acceso directo
  • Pilas: LIFO, ideal para recursión y deshacer/rehacer
  • Colas: FIFO, perfectas para procesos y planificación
  • Sets/Dicts: Búsqueda O(1), sin duplicados, mapeo clave-valor
  • Árboles: Búsqueda jerárquica eficiente, recorridos especiales

Criterios de Selección

Considera usar:

  • Lista: Si necesitas orden y acceso por índice
  • Set: Si necesitas unicidad y búsqueda rápida
  • Dict: Si mapeas claves a valores
  • Pila/Cola: Si el orden de procesamiento importa
  • Árbol: Si los datos son jerárquicos

Factores clave:

  • Frecuencia de operaciones
  • Requisitos de memoria
  • Complejidad temporal
  • Naturaleza de los datos
  • Facilidad de implementación

💡 Recuerda: No existe una estructura "mejor", solo la más adecuada para cada problema.
